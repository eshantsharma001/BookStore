# 📚 BookStore

A full-stack bookstore web app where users can browse, buy, and add new books to the catalog. Built with Node.js, Express, MongoDB, and EJS templates.

## ✨ Features

- 🛒 Browse and purchase books
- ➕ Add new books to the store
- 📖 View book details (title, author, price, description)
- 🔍 Search and filter available titles
- 🗄️ Persistent storage with MongoDB

## 🛠️ Tech Stack

- **Backend:** Node.js, Express
- **Templating:** EJS
- **Database:** MongoDB (Mongoose)
- **Styling:** Bootstrap *(change to Tailwind CSS if that's what you used)*
